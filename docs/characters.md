# 캐릭터와 말투

인덱스는 게임 내부 인스트럭터/CPU 번호다(`$8DBF`, 이름 테이블 `$00:CFDF`). i00은 플레이어 자신이 사범대리일 때 쓰는 자리로, i01과 같은 조언 테이블을 공유한다.
