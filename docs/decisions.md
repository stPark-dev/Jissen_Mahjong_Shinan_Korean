## 기술 결정 (에이전트 재량, 채택된 의도 유지)
- T-001: 10px급 작은 그림 라벨(이름 입력 탭 등)은 Neo둥근모 16px가 들어가지 않아 **갈무리11 Bold**(OFL, `sha256 45d901e3…`)를 쓴다. 16px 칸은 계속 Neo둥근모.
- T-002: 단위 그림 글리프(#66)는 가로·세로 배치를 함께 지원하려고 글자 대 글자로 치환한다. 3칸 고정인 師範代는 "사범대"로 표기한다(텍스트 경로는 "사범대리").
- T-003: 이름 입력 격자는 2쪽 × 85칸 = 170음절(`data/name_entry.txt`, 가나다순). 탭 이름은 "가~" / "어~".
- T-004: 순수 그림/글리프 시트 화면(플레이 데이터 #57 등)은 소비 문자열을 모두 열거하지 못해도 안전하도록 글자 대 글자로 치환한다(한자음·음차). 四는 한 글리프이므로 四暗刻·四槓子는 "사안커"·"사깡쯔"가 된다(대국 화면 TPG는 "스안커"·"스깡쯔").
- T-005: 큰 간판(지남 소개 "麻雀指南", 약 24px)은 **나눔명조 ExtraBold**(OFL, `sha256 a03d520b…`)로 안티앨리어싱해 원본 먹색 단계로 양자화한다. 10px 버튼(상대 선택 "決定")은 **갈무리9**(OFL, `sha256 e84e821b…`).
